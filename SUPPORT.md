# Support

Warm Path Audit is community-maintained reference software with no warranty or support SLA.

## Use the right route

- **Usage question or possible bug:** open a GitHub issue using the available template and a synthetic reproduction.
- **Feature or design proposal:** use the feature template and explain safety/privacy impact.
- **Security vulnerability:** follow [`SECURITY.md`](SECURITY.md); never disclose it publicly first.
- **Private customer, contributor, or relationship data:** do not post it. Minimize the example with fictional names and reserved domains.

Before filing, run:

```sh
npm run check
npm run build
npm run demo
```

Include Node.js version, OS, package version/commit, exact command with secrets/paths removed, expected behavior, actual sanitized behavior, and relevant reason/error codes.

## Not provided

Maintainers cannot provide legal advice, provider terms interpretation, production deployment approval, managed introductions, data enrichment, CRM operations, or emergency incident response through public issues.

Third-party product questions belong with their respective providers. Illustrative Attio, HubSpot, Salesforce, and LinkedIn references do not constitute support for those platforms.
